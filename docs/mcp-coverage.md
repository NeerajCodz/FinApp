# MCP coverage

Every public Convex function that backs a user-facing capability, mapped to the
MCP tool that exposes it. Inventory taken on `release/v1.11.1` (FinApp 1.11.1).

- **Status**: `existing` = tool already shipped; `new` = added in this pass;
  `covered` = reachable through another tool; `excluded` = deliberately not
  exposed (reason in the notes); `n/a` = not a user capability.
- **Scope** shortens `finapp:read` to `read` and `finapp:write:<x>` to `write:<x>`.
- Tool count: 101 domain tools before, 114 after (plus `finapp.catalog` and 4
  `finapp.<domain>.parent` discovery tools).

## Not user capabilities through MCP

| Area                                          | Functions                                                                                                                   | Reason                                                                               |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| FinAI assistant chat, actions, keys, receipts | `ai/assistant:*`, `ai/actions:*`, `ai/keys:*`, `ai/attachments:*`, `ai/receipts:*`                                          | The MCP client is itself the assistant; API keys are secrets; receipts need uploads. |
| Sign-in and app lock                          | `auth:*`, `authEmailChallenges`, `mfa:*` actions                                                                            | Authentication internals.                                                            |
| MCP connection management                     | `mcpOAuth:*`, `mcpOAuthActions:*`                                                                                           | A connection must not widen or manage its own access.                                |
| Client sync                                   | `sync/queries:*`                                                                                                            | Device sync protocol; MCP uses bounded reads instead.                                |
| Presence and push                             | `presence/mutations:heartbeat`, `setTyping`, `presence/queries:scopeState`, `notifications/push:*`, `security:touchSession` | Device-only signals.                                                                 |
| System                                        | `system:info`, `migrations`, crons                                                                                          | Operational.                                                                         |
