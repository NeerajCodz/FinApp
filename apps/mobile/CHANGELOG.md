# Mobile app (@finapp/mobile)

Versions are tracked in the root `version.json`; see `docs/versioning.md`.

## 1.11.0

- Budget screens removed (old routes open Categories); category limits with alert levels
- Charts from `@finapp/ui/charts` across analytics, home, categories and goals
- Notifications inbox (swipe actions, pull to refresh), profile edit (photo upload) and About
  redesigned
- "Lock after" setting for the app lock (default 5 minutes)

## 1.10.1

- Redesigned app lock screen (brand, avatar in accent ring, name, @username, sign out)
- Two-factor step with authenticator, email and recovery codes; authenticator app (QR, key,
  open-in-app link) and recovery code settings in Security
- Signed-in users are sent from the welcome and sign-in screens to the app

## 1.10.0

- Tab bar: Home, Activity, +, People, Profile; sync and notifications on Home; Trash screen and
  settings; compact profile tiles with Trash
- FinAI: live text with smooth reveal; launcher orb and unread badge; toast with Open on any
  screen; attachments from Photos, Camera or Files; attachment settings
- MCP access control, per-app permissions, dashboard shortcuts
- Redesigned Security (devices, sign-in alerts, app lock), Privacy, Appearance, Currency,
  Notifications and Sync settings

## 1.9.0

- Settings hub and Profile AI section; FinAI, API keys and MCP connections screens
- Floating FinAI button and step list follow FinAI settings
