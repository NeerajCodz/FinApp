Build local-calendar boundaries in the saved profile timezone (UTC when no profile timezone exists): Monday-start week, calendar month, calendar year; the previous window is the immediately preceding corresponding calendar period. Use half-open bounds `[startAt, endAt)`.
   - Extend `AnalyticsTransaction` with optional `accountId`, `merchant`, and `title`; define `AnalyticsAccount = { id: string; name: string; aliases?: readonly string[] }` and `AnalyticsCategory = { id: string; name: string; aliases?: readonly string[] }`. Bucket week by seven local calendar days, month by each local calendar date in the month, and year by twelve local calendar months.
